**Время затраченное на разработку концепции, написание кода, поиск решений, тесты - примерно 1.5 - 2 часа с перерывами. **

### Требования

- Node.js версии 18.0 или выше
- npm или yarn

### Установка и запуск

1. **Клонируйте репозиторий**:
```bash
git clone <url-репозитория>
cd todo-list_task
```

2. **Установите зависимости**:
```bash
npm install
```

3. **Запустите в режиме разработки**:
```bash
npm run dev
```

Приложение откроется по адресу `http://localhost:5173` (или другом порту, указанном в терминале).

## 🧪 Тестирование

Запуск всех тестов:
```bash
npm run test
```

Запуск с UI-интерфейсом:
```bash
npm run test:ui
```

Проверка покрытия кода:
```bash
npm run test:coverage
```
