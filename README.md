# To Do List

Современное приложение для управления задачами с адаптивным дизайном, поддержкой фильтрации и поиска.

## 🚀 Быстрый старт

### Требования

- Node.js версии 18.0 или выше
- npm или yarn

### Установка и запуск

1. **Клонируйте репозиторий** (если ещё не сделано):
```bash
git clone <url-репозитория>
cd todo-list_task
```

2. **Установите зависимости**:
```bash
npm install
```

3. **Запустите в режиме разработки**:
```bash
npm run dev
```

Приложение откроется по адресу `http://localhost:5173` (или другом порту, указанном в терминале).

## 📜 Доступные команды

| Команда | Описание |
|---------|----------|

## 🛠️ Технологии

### Core
- **React 19** — библиотека для построения пользовательских интерфейсов
- **TypeScript 7** — типизированный JavaScript для надёжного кода
- **Vite 8** — быстрый сборщик и dev-сервер

### Стилизация
- **Tailwind CSS 4** — utility-first CSS фреймворк
- **class-variance-authority** — управление вариантами компонентов
- **clsx + tailwind-merge** — условное объединение классов

### Управление состоянием
- **Zustand 5** — лёгкая библиотека для state management с поддержкой persist middleware

### Утилиты
- **nanoid** — генератор уникальных ID

### Тестирование
- **Vitest** — быстрый тестовый раннер на базе Vite
- **Testing Library** — утилиты для тестирования React-компонентов
- **jsdom** — реализация DOM для Node.js

### Code Quality
- **oxlint** — быстрый линтер для JavaScript и TypeScript

## 📱 Адаптивность

Приложение полностью адаптивно и корректно отображается на всех устройствах:

- 📱 **Mobile** — до 640px
- 📱 **Tablet** — 640px - 1024px
- 💻 **Desktop** — 1024px и выше

## ✨ Основные возможности

- ✅ Создание, редактирование и удаление задач
- 🔍 Поиск задач по названию
- 🏷️ Фильтрация (все / активные / завершённые)
- 💾 Автосохранение в localStorage
- 📱 Адаптивный дизайн для всех устройств
- 🧪 Полное покрытие тестами (49 тестов)

## 📁 Структура проекта

```
src/
├── app/              # Корневой компонент приложения
├── entity/           # Бизнес-сущности (Task)
├── features/         # Функциональные возможности (фильтры, поиск)
├── widgets/          # Составные блоки (AddTaskBar, TaskList)
├── shared/           # Переиспользуемые компоненты (Button, Input)
└── store/            # Zustand store
```

Архитектура основана на принципах **Feature-Sliced Design**.
